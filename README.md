# 像素校园 · 延边大学（延吉校区）

用代码把延边大学延吉校区画成一张「星露谷风」像素地图：道路、建筑、绿地全部由程序生成，可缩放浏览。

## 预览

![预览图](说明/预览图.png)

## 特性

- 按《延边大学建筑分布图》还原道路与建筑
- 星露谷像素风：草地噪点、花丛、树、瓦楞屋顶、铺装碎石
- 分块烘焙渲染（4×3 块，256×256），运行时只做 `drawImage`
- 响应式布局，适配手机屏幕
- 缩放 100% ~ 400%
- 纯前端，无后端依赖

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:5173/

## 目录结构

```
源码/
  像素绘制.js    像素绘制库（颜色打包 / 画点 / 帧缓冲）
  地图数据.js    类别网格数据（由建筑分布图生成）
  地面渲染.js    地面渲染（草地 / 铺装 / 绿地 / 建筑）
  分块渲染.js    分块烘焙与缓存
  主程序.js      页面装配与交互
  样式.css       页面样式
工具/
  图片编码.mjs   PNG 编码器
  生成预览图.mjs 生成预览图并校验分块拼装
说明/
  预览图.png     地图预览图
public/
  建筑/          24 张建筑精灵图（实验产物，页面暂未使用）
  图标.svg       网站图标
index.html       页面入口（文件名不能改）
package.json     项目配置（文件名不能改）
```

> 说明：`index.html`、`package.json`、`.gitignore`、`LICENSE`、`README.md`、`.github/` 这些是有工具/平台格式要求的，保持英文原名。

## 数据是怎么来的

1. 以《延边大学（延吉校区）建筑分布图》为源图
2. 按颜色分类：白色→铺装/道路、绿色→绿地、米黄→教学楼、蓝→宿舍
3. 降采样成 256×179 的类别网格（`源码/地图数据.js`）
4. 渲染时逐格绘制星露谷风材质

想重新生成预览图：

```bash
node 工具/生成预览图.mjs
```
